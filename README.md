# Songsong Mo — Academic Homepage

This repository contains the static files for <https://songsongmo.cn/>.

## Updating the site

- Edit `index.html` for the homepage, projects, selected publications, and news.
- Edit `research/index.html` for the research programme.
- Edit `publications/index.html` for the complete publication list.
- Edit `assets/css/site.css` for the visual system and responsive layout.

The site is plain HTML and CSS and is served directly by GitHub Pages. It has no build step.
